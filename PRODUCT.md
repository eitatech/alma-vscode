# Product

## Register

product

## Users

Software developers working inside VS Code-compatible editors who use spec-driven workflows and need to start, observe, steer, and resume local or cloud coding agents without leaving their workspace.

## Product Purpose

GatomIA brings specifications, repository guidance, automation, and agent execution into one editor-native workspace. The agent chat must make the current agent, model, permission policy, execution progress, tool activity, file changes, and next available action immediately understandable while preserving the speed and familiarity of VS Code.

## Brand Personality

Native, precise, and dependable. The interface should feel like a well-integrated part of the editor rather than a separate web application, with compact information density and calm operational feedback.

## Anti-references

- Generic SaaS dashboards that ignore VS Code theme tokens and interaction patterns.
- Oversized cards, ornamental chrome, decorative gradients, and excessive rounding.
- Chat interfaces that hide agent activity, permissions, tool calls, or file impact behind undifferentiated transcript text.
- Dense control rows without progressive disclosure, keyboard support, or narrow-sidebar behavior.

## Design Principles

- Keep the developer in flow by making the next action obvious and nearby.
- Show agent progress as structured, scannable activity rather than raw protocol noise.
- Preserve trustworthy context: agent, model, mode, permissions, workspace, and affected files.
- Prefer editor-native controls, tokens, icons, focus behavior, and terminology.
- Reveal detail progressively while keeping errors and approval requests actionable.

## Accessibility & Inclusion

Follow VS Code accessibility and UX conventions, including theme and high-contrast tokens, complete keyboard operation, visible focus, semantic labels, reduced-motion support, and information that does not rely on color alone. Text and controls must remain legible in narrow sidebars and under text zoom.
