## 1. Agent Chat sidebar — resolve, route, bind 🟢

```mermaid
flowchart TD
    A([resolveWebviewView]) --> B[set html = get-webview-content agent-chat/sidebar]
    B --> C[wire onDidReceiveMessage]
    C --> D[pushCatalog + pushSessionList + pushPermissionDefault]
    D --> E{pendingFocusSessionId?}
    E -- yes --> F[bindSession id]
    E -- no --> G([idle / empty launcher])

    G --> H([webview message])
    H --> I{type}
    I -- agent-chat/ready --> D
    I -- control/switch-session --> F
    I -- control/new-session --> J[dispatchNewSessionFromComposer]
    I -- control/request-new-chat --> K[startNewSessionFlow -> session/cleared]
    I -- control/change-permission-default --> L[update Global config -> listener rebroadcasts]
    I -- control/probe-models --> M[triggerModelProbe invalidate]
    I -- default --> N{binding?}
    N -- yes --> O[binding.handleWebviewMessage]
    N -- no --> G

    J --> P[executeCommand gatomia.agentChat.startNew]
    P --> Q[bind newest registered session]
    Q --> F
```

## 2. SidebarSessionBinding — submit + delta sync 🟢

```mermaid
flowchart TD
    A([input/submit]) --> B{sessionId == bound?}
    B -- no --> Z([ignore])
    B -- yes --> C[build pending UserChatMessage]
    C --> D{source == cloud?}
    D -- yes --> D1[append + reject: read-only] --> Z
    D -- no --> E{terminal lifecycle?}
    E -- yes --> E1[append + reject: terminal] --> Z
    E -- no --> F{runner attached?}
    F -- no --> F1[append + reject: no runner] --> Z
    F -- yes --> G[messages/appended pending]
    G --> H{runner.submit?}
    H -- no --> H1[update -> rejected: no follow-up] --> Z
    H -- yes --> I[runner.submit content]
    I -- ok --> J[update -> delivered]
    I -- throw --> K[update -> rejected: err.message]

    subgraph reactive [onDidChangeManifest]
      M([manifest changed]) --> N{lifecycle changed?}
      N -- yes --> N1[post session/lifecycle-changed]
      N --> O[maybePushModelsChanged - diff ids/current]
      O --> P[flushTranscriptDeltas - diff by knownMessageIds]
      P --> Q[messages/appended only fresh]
    end
```
