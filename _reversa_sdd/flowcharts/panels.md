## 1. Webview-readiness message gate (welcome / document-preview) 🟢

```mermaid
stateDiagram-v2
    [*] --> no_panel
    no_panel --> created: ensurePanel() (createWebviewPanel + set html)
    created --> created: postMessage(...) -> queue in pendingMessages (not ready)
    created --> ready: webview posts '*/ready' (isWebviewReady=true)
    ready --> ready: flushPendingMessages() FIFO -> webview.postMessage
    ready --> no_panel: onDidDispose / dispose() (reset ready=false, clear queue)
    created --> no_panel: dispose()
```

## 2. AgentChatPanel — open → message plumbing → dispose 🟢

```mermaid
flowchart TD
    A([open]) --> B{opened && panel?}
    B -- yes --> B1[reveal Beside] --> Z([return])
    B -- no --> C[host.createPanel session]
    C --> D[wire onDidReceiveMessage / onDidDispose]
    D --> E[subscribe store.onDidChangeManifest]
    E --> F[telemetry PANEL_OPENED]
    F --> G([ready])

    G --> H([webview message])
    H --> I{type}
    I -- agent-chat/ready --> J[sendSessionLoaded: session snapshot + transcript]
    I -- input/submit --> K[handleInputSubmit]
    I -- control/cancel --> L[runner.cancel]
    I -- control/retry --> M[runner.retry?]

    subgraph manifest [onManifestChanged]
      N([manifest changed]) --> N1{lifecycleState != last?}
      N1 -- yes --> N2[post session/lifecycle-changed from->to]
      N1 -- no --> N3[skip]
      N2 --> N4[flushTranscriptDeltas]
      N3 --> N4
      N4 --> N5[diff transcript vs knownMessageIds -> append fresh]
    end
```

## 3. handleInputSubmit — optimistic send + delivery lifecycle 🟢

```mermaid
flowchart TD
    A([input/submit content]) --> B[build pending UserChatMessage]
    B --> C{source == cloud?}
    C -- yes --> C1[append + patch rejected: read-only cloud] --> Z([done])
    C -- no --> D{TERMINAL_STATES has lifecycleState?}
    D -- yes --> D1[append + patch rejected: terminal state] --> Z
    D -- no --> E{runner attached?}
    E -- no --> E1[append + patch rejected: no runner] --> Z
    E -- yes --> F[messages/appended pending]
    F --> G{runner.submit exists?}
    G -- no --> G1[patch rejected: no follow-up] --> Z
    G -- yes --> H[await runner.submit content]
    H -->|ok| H1[patch deliveryStatus=delivered] --> Z
    H -->|throws| H2[patch rejected: error.message] --> Z
```

## 4. NewSessionPanel — start → handoff (self-dispose) 🟢

```mermaid
flowchart TD
    A([open]) --> B{disposed?}
    B -- yes --> B0[throw: cannot open disposed] 
    B -- no --> C{panel exists?}
    C -- yes --> C1[reveal] --> Z([shown])
    C -- no --> D[createWebviewPanel + stub html]
    D --> E[subscribe registryUpdateEvent -> broadcastProviders]
    E --> F[broadcastProviders: post new-session/providers]
    F --> Z

    Z --> G([webview: new-session/start])
    G --> H{isStartPayload?}
    H -- no --> H0[ignore]
    H -- yes --> I[try onStart payload]
    I --> J[finally: dispose - hand off to real Agent Chat panel]
```
