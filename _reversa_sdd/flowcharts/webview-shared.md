> The cross-cutting webview infrastructure: single-bundle entry, runtime page router, the VS Code postMessage bridge, themed primitives, and shared utilities consumed by every other webview module.

## 1. Single-bundle bootstrap + runtime page selection 🟢

> `index.tsx` + `page-registry.tsx`. Vite builds **one** bundle (`ui/vite.config.ts`); the active page is chosen at runtime from the host-set `data-page` attribute on `#root`.

```mermaid
flowchart TD
    A([index.tsx loads]) --> B[createRoot of #root]
    B --> C[page = container.dataset.page or 'simple']
    C --> D[getPageRenderer pageName]
    D --> E{pageName in pageRenderers?}
    E -- no --> E0[render 'Unknown page: name']
    E -- yes --> F[withSuspense lazy-imported feature]
    F --> G[code-split chunk loads on demand]
    G --> H[feature mounts + opens its own bridge channel]

    subgraph PAGES[11 registered pages]
      P[simple · interactive · create-spec · create-steering · hooks ·<br/>document-preview · welcome-screen · agent-chat · orchestration · workflow-composer]
    end
    D -.-> PAGES
```

> 🔴 GAP: panels `devin-progress-panel` / `cloud-agent-progress-panel` set `data-page` values (`devin-progress` / `cloud-agent-progress`) that are **not** in `pageRenderers` → those panels hit the `Unknown page` branch (see `webview-orchestration` §4).

## 2. VS Code bridge resolution (host vs dev fallback) 🟢

> `bridge/vscode.ts` — resolved **once** at import. The shared channel; some modules (`spec-explorer`) deliberately acquire their own instead.

```mermaid
flowchart TD
    A([import bridge/vscode]) --> B{window.acquireVsCodeApi is function?}
    B -- yes --> C[vscodeApi = window.acquireVsCodeApi&#40;&#41;<br/>real postMessage / getState / setState]
    B -- no --> D[dev fallback: postMessage echoes openspec.chat/echoResult after 50ms<br/>getState -> &#123;&#125;, setState -> no-op]
    C --> E[export const vscode]
    D --> E
```

## 4. `formatRelativeTime` thresholds 🟢

> `utils/relative-time.ts` — shared by `welcome/status-section` and `agent-chat/sessions-list`.

```mermaid
flowchart TD
    A[diff = now - timestamp] --> B{diff < 60s?}
    B -- yes --> B1[just now]
    B -- no --> C{minutes < 60?}
    C -- yes --> C1[Nm ago]
    C -- no --> D{hours < 24?}
    D -- yes --> D1[Nh ago]
    D -- no --> E{days < 7?}
    E -- yes --> E1[Nd ago]
    E -- no --> F[N wk ago]
```

## 5. `toFriendlyName` filename → title 🟢

> `lib/document-title-utils.ts` (sole consumer: `preview-app.tsx`; grouped here as a shared lib util).

```mermaid
flowchart LR
    A[filename] --> B[take basename after last /]
    B --> C[strip extension .ext]
    C --> D[strip leading 'NNN-']
    D --> E[replace - and _ with space]
    E --> F[Title-Case each word]
    F --> G[friendly name]
```
