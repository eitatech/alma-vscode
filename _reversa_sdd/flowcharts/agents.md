# Flowcharts — `agents` module

> Source: `src/features/agents/`. Confidence: 🟢 CONFIRMED unless noted.
> Generated by the Reversa Archaeologist (escavação phase).

## 1. Discovery → registration → chat request handling

```mermaid
flowchart TD
    A([Extension init]) --> B{Copilot Chat API available?}
    B -- no --> B0[log + skip] --> Z([End])
    B -- yes --> C[AgentLoader.loadAgents agentsDir]
    C --> D{dir exists?}
    D -- no --> D0[return empty] --> Z
    D -- yes --> E[readDirectory recursive]
    E --> F{file ends with .agent.md?}
    F -- no --> E
    F -- yes --> G[parseAgentFile: gray-matter frontmatter]
    G --> H{frontmatter present?}
    H -- no --> H0[log parse error, skip] --> E
    H -- yes --> I[extract id/name/fullName/description/commands/resources]
    I --> J{has /help command?}
    J -- no --> J0[auto-inject /help -> tool agent.help]
    J0 --> K[build AgentDefinition]
    J -- yes --> K
    K --> L[validateDefinition]
    L --> M{valid?}
    M -- no --> M0[log validation errors, skip] --> E
    M -- yes --> N[add to agents]
    N --> E
    E --> O[for each agent: registerAgent]
    O --> P{already registered?}
    P -- yes --> O
    P -- no --> Q[chat.createChatParticipant + icon + followups]
    Q --> R[ResourceCache.load prompts/skills/instructions]
    R --> S[FileWatcher.watch resourcesDir]
    S --> T([Ready])

    T --> U([User: @agent /command args])
    U --> V[handleChatRequest: parse command]
    V --> W{command found?}
    W -- no --> W0[render not-found / help] --> ZZ([Done])
    W -- yes --> X[loadAgentResources from cache]
    X --> Y[ToolRegistry.execute name, params]
    Y --> Y1{handler found?}
    Y1 -- no --> Y2[throw: available tools list] --> ERR
    Y1 -- yes --> Y3[run handler with timing]
    Y3 --> Y4{success?}
    Y4 -- yes --> Y5[add duration to metadata] --> Y6[stream.markdown response] --> ZZ
    Y4 -- no --> ERR[wrap ToolExecutionError]
    ERR --> ERR1[formatError + categorize + sanitize]
    ERR1 --> ERR2[render user msg + guidance + technical details]
    ERR2 --> ERR3[error telemetry + severity log] --> ZZ
```

## 2. Resource cache lifecycle (hot-reload) 🟢

```mermaid
stateDiagram-v2
    [*] --> empty
    empty --> loaded: load() scans prompts/skills/instructions in parallel
    loaded --> pending_reload: FileWatcher onDidChange/Create/Delete (add to pending)
    pending_reload --> reloading: debounce 500ms -> flushPendingChanges()
    reloading --> loaded: reload() per file (read=update, missing=delete)
```

## 3. Tool execution lifecycle 🟢

```mermaid
stateDiagram-v2
    [*] --> validating: execute(name, params)
    validating --> not_found: handler missing
    validating --> executing: handler found (start timing)
    not_found --> [*]: throw Error (available tools)
    executing --> completed: success (duration -> metadata)
    executing --> failed: handler throws
    failed --> [*]: wrap + formatError + log + rethrow ToolExecutionError
    completed --> [*]: return ToolResponse
```
