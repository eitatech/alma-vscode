# Flowcharts — `cloud-agents` module

> Source: `src/features/cloud-agents/`. Confidence: 🟢 CONFIRMED unless noted.
> Generated by the Reversa Archaeologist (escavação phase).

## 1. Create a cloud-agent session via a provider

```mermaid
flowchart TD
    A([Dispatch task to cloud provider]) --> B{active provider configured?}
    B -- no --> B0[Error: no active provider] --> Z([End])
    B -- yes --> C[registry.getActive]
    C --> D{provider has credentials?}
    D -- no --> E[prompt for credentials]
    E --> F{saved?}
    F -- no --> F0[Error: credentials required] --> Z
    F -- yes --> G[provider.createSession task, context]
    D -- yes --> G
    G --> H{Devin or GitHub?}
    H -- Devin --> I[build referential prompt from spec artifacts]
    I --> J[Devin API createSession]
    J --> K[map -> AgentSession, providerSessionId = devin session id]
    H -- GitHub --> L[resolve repo id via GraphQL]
    L --> M[build issue body]
    M --> N[create issue with agentAssignment]
    N --> O[map -> AgentSession, providerSessionId = owner/repo#number]
    K --> P[storage.create session, status = PENDING]
    O --> P
    P --> Q[fire onUpdated -> UI] --> Z
```

## 2. Polling loop updating status (with backoff + terminal normalization)

```mermaid
flowchart TD
    A([interval fires / force refresh]) --> B[pollOnce force?]
    B --> C{active provider set?}
    C -- no --> C0[skip] --> Z([End])
    C -- yes --> D{force?}
    D -- yes --> E[all non-read-only sessions]
    D -- no --> F[active + grace-period sessions<br/>5m known PR / 1h unknown; exclude terminal PRs]
    E --> G[provider.pollSessions]
    F --> G
    G --> H{poll succeeded?}
    H -- no --> I[consecutiveFailures++]
    I --> J{credential error?}
    J -- yes --> J1[fire onCredentialExpiry] --> Z
    J -- no --> K{>= 3 failures?}
    K -- yes --> K1[stop interval] --> Z
    K -- no --> K2[fire onError] --> Z
    H -- yes --> L[consecutiveFailures = 0]
    L --> M[for each SessionUpdate]
    M --> N{has changes?}
    N -- no --> M
    N -- yes --> O{terminal status?}
    O -- yes --> P[derive task statuses from session status]
    O -- no --> Q[use provided tasks]
    P --> R[merge to storage; set updatedAt/completedAt]
    Q --> R
    R --> S[fire onSessionUpdated -> agent-chat bridge]
    S --> T{status == COMPLETED?}
    T -- yes --> T1[fire onSessionCompleted]
    T -- no --> U[continue]
    T1 --> U
    U --> M
```

## 3. Terminal-state normalization (`normalizeSession`) 🟢

```mermaid
flowchart TD
    A([session loaded / updated]) --> B[normalizeSession]
    B --> C{status terminal?<br/>COMPLETED/FAILED/CANCELLED}
    C -- no --> D[return as-is]
    C -- yes --> E{any non-terminal task?}
    E -- yes --> F[task.status = SESSION_TO_TASK_STATUS,<br/>else SKIPPED; completedAt = now]
    E -- no --> G[no task change]
    F --> H{any PR state undefined?}
    G --> H
    H -- yes --> I{status == COMPLETED?}
    I -- yes --> J[pr.state = merged]
    I -- no --> K[pr.state = open]
    H -- no --> L[return as-is]
    J --> M[return normalized]
    K --> M
```

## 5. Session cleanup (7-day retention) 🟢

```mermaid
flowchart TD
    A([cleanup triggered]) --> B[cutoff = now - 7 days]
    B --> C[get expired sessions]
    C --> D{any expired?}
    D -- no --> E[return 0]
    D -- yes --> F[delete each expired session]
    F --> G[log count] --> H[return count]
```
