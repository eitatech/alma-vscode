## 1. End-to-end flow: start ACP session → process turn → tool calls → archive

```mermaid
flowchart TD
    A([User: New Agent Chat]) --> B{checkCapacity<br/>acp sessions >= cap?}
    B -- yes --> B1[promptForCapWarning QuickPick]
    B1 --> B2[cancel chosen idle session]
    B2 --> C
    B -- no --> C[store.createSession]
    C --> D[resolve capabilities<br/>agent-reported vs catalog]
    D --> E{executionTarget.kind<br/>== worktree?}
    E -- yes --> E1[worktreeService.create<br/>git worktree add -b]
    E -- no --> F
    E1 --> F[new AcpChatRunner -> start]
    F --> G[subscribe ACP events<br/>transition: running]
    G --> H[append initial user message<br/>deliveryStatus = delivered]
    H --> I[dispatchToAcp: turnInFlight = true]
    I --> J{{ACP event stream}}

    J -->|agent-message-chunk| K1[coalesce into turn buffer<br/>create/update AgentChatMessage]
    J -->|agent-thought-chunk| K2[update ThoughtChatMessage]
    J -->|plan-update| K3[idempotent PlanChatMessage]
    J -->|tool-call| K4[create ToolCallChatMessage<br/>status = pending]
    J -->|tool-call-update| K5[patch status + affectedFiles]
    J -->|writeTextFile RPC| W1[pendingWritesStore.enqueueWrite<br/>emit pending-writes/changed]
    J -->|error| ERR[emit ErrorChatMessage<br/>transition: failed]
    J -->|turn-finished| T

    W1 --> W2{user Accept / Reject}
    W2 -- accept --> W3[host writes file to disk]
    W2 -- reject --> W4[resolve rejected]
    W3 --> J
    W4 --> J

    K1 --> J
    K2 --> J
    K3 --> J
    K4 --> J
    K5 --> J

    T{queuedFollowUp exists?}
    T -- yes --> T1[mark queued -> delivered<br/>dispatchToAcp next turn]
    T1 --> I
    T -- no --> T2[transition: waiting-for-input]
    T2 --> U{user submits follow-up?}
    U -- yes, turn idle --> H2[append delivered + dispatch]
    H2 --> I
    U -- yes, turn in-flight --> Q[append queued<br/>store in queuedFollowUp]
    Q --> J
    U -- cancel --> X1[manager.cancel<br/>transition: cancelled]
    U -- deactivate --> X2[flushForDeactivation<br/>ended-by-shutdown]

    X1 --> CL
    X2 --> CL
    ERR --> CL
    CL{worktree exists?}
    CL -- yes --> CL1[worktreeService.cleanup<br/>inspect -> warn if dirty]
    CL1 --> CL2[registry.removeSession]
    CL -- no --> CL2
    CL2 --> Z([End])

    %% Archival is checked on every appendMessages
    K1 -.->|threshold >10k msgs or >2MB| AR[archive oldest 25% to JSONL]
```

## 2. Session lifecycle state machine 🟢

> `types.ts:18-43`, `acp-chat-runner.ts:890-911`. Terminal states are absorbing.

```mermaid
stateDiagram-v2
    [*] --> initializing
    initializing --> running: start()
    running --> waiting_for_input: turn finished, no queued follow-up
    waiting_for_input --> running: user submits follow-up
    running --> completed: agent turn finishes naturally
    running --> failed: dispatchToAcp throws / runtime error
    initializing --> cancelled: cancel()
    running --> cancelled: cancel()
    waiting_for_input --> cancelled: cancel()
    initializing --> ended_by_shutdown: extension deactivates
    running --> ended_by_shutdown: extension deactivates
    waiting_for_input --> ended_by_shutdown: extension deactivates
    completed --> [*]
    failed --> [*]
    cancelled --> [*]
    ended_by_shutdown --> [*]
```
