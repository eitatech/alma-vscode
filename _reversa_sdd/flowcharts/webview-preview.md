
## 4. Interactive form: init → validate → submit (form-store FSM) 🟢

> `components/forms/preview-form-container.tsx` + `features/preview/stores/form-store.ts` + `api/form-bridge.ts`.

```mermaid
stateDiagram-v2
    [*] --> empty
    empty --> initialized: initializeFields(documentId, sessionId, fields, readOnly)
    initialized --> dirty: updateField(id,value) [not readOnly, field editable]
    dirty --> dirty: validateField (required / option / minLength / maxLength / pattern)
    dirty --> submitting: prepareSubmission() OK (validateAll passes, has dirty)
    dirty --> dirty: validateAll fails -> validationErrors (blocked)
    submitting --> submitted: bridge resolves -> markSubmitted (clear dirty, stamp lastSubmittedAt)
    submitting --> dirty: bridge rejects / timeout (re-enable)
    initialized --> empty: reset() on unmount / new document
    note right of dirty
      readOnlyMode blocks updateField + prepareSubmission
      submitForm rejects when 0 dirty fields; 10s timeout
    end note
```
