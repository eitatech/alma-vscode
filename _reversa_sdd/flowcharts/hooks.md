## 1. End-to-end: operation completion → hook action 🟢

```mermaid
flowchart TD
    A([Agent operation runs e.g. /speckit.specify]) --> B[CommandCompletionDetector: FileSystemWatcher]
    B --> C{file matches operation pattern? e.g. specs/*/spec.md}
    C -- no --> Z([wait])
    C -- yes --> D[parse-validate file + debounce 2s]
    D --> E[TriggerRegistry.fireTrigger agent, operation, timing]
    E --> F[onTrigger event -> HookExecutor.executeHooksForTrigger]
    F --> G[match enabled hooks by agent+operation+timing, sort by createdAt]
    G --> H{any matches?}
    H -- no --> Z
    H -- yes --> I[create shared ExecutionContext]
    I --> J[for each hook: executeHook]
    J --> K([results])
```

## 2. Single-hook execution pipeline 🟢

```mermaid
flowchart TD
    A([executeHook]) --> B{hook.enabled?}
    B -- no --> B0[status=skipped] --> Z([record log])
    B -- yes --> C{action.type == mcp?}
    C -- yes --> C1[validate MCP server/tool]
    C1 --> C2{valid?}
    C2 -- no --> C3[prompt user: Update Hook] --> Z
    C -- yes/after check --> D{action.type == custom?}
    D -- yes --> D1[check agent availability]
    D1 --> D2{available?}
    D2 -- no --> D3[prompt: Retry / Update Hook / handle FILE_DELETED] --> Z
    D -- proceed --> E[evaluate conditions]
    E --> F{conditions met?}
    F -- no --> F0[status=skipped] --> Z
    F -- yes --> G{schedule.type}
    G -- delayed --> G1[await delayMs]
    G -- immediate --> H
    G1 --> H[build TemplateContext + expandTemplate args]
    H --> I[dispatch by action.type]
    I --> I1[agent]
    I --> I2[git]
    I --> I3[github via MCP]
    I --> I4[mcp tool]

    J -- failure --> J2[capture ExecutionError + telemetry failure]

```

## 3. Trigger matching + blocking decision 🟢

```mermaid
flowchart TD
    A([executeHooksForTrigger agent, op, timing]) --> B[getAllHooks]
    B --> C[filter: enabled AND trigger/events match agent+op+timing]
    C --> D[sort by createdAt deterministic]
    D --> E[for each matching hook]
    E --> F{timing==before AND waitForCompletion?}
    F -- yes --> G[BLOCKING: await executeHook before proceeding]
    F -- no --> H[await executeHook]
    G --> I[push result]
    H --> I
    I --> E
    I --> Z([return results])
```

> 🟡 Note: both branches `await` sequentially in the loop; the "non-blocking / parallel" comment in code does not produce true parallelism (`hook-executor.ts:884-895`).

## 5. Hook load + schema migration 🟢

```mermaid
flowchart TD
    A([loadHooks from workspaceState]) --> B[for each stored hook: migrateHook]

```
