## 1. Task initiation → session creation 🟢

```mermaid
flowchart TD
    A([User: Run task with Devin]) --> B[validateGitState]
    B --> C{git repo & clean?}
    C -- no --> C0[showGitValidationError + abort] --> Z([End])
    C -- yes --> D[commitAndPush: git add -A -> commit if changes -> push origin branch]
    D --> E{push ok?}
    E -- no --> E0[surface git error] --> Z
    E -- yes --> F[DevinSessionManager.startTask / startTaskGroup]
    F --> G[mapSpecTaskToDevinPrompt / mapTaskGroupToDevinPrompt]
    G --> H[resolveApiClient]
    H --> I{client cached?}
    I -- no --> I1[credentials.getOrThrow] --> I2[detectApiVersion by token prefix]
    I2 --> I3{cog_ prefix?}
    I3 -- yes --> I4{orgId present?}
    I4 -- no --> I5[throw DevinOrgIdRequiredError] --> Z
    I4 -- yes --> I6[new DevinApiClientV3 org-scoped]
    I3 -- no --> I7[new DevinApiClientV1 v1/v2]
    I -- yes --> J
    I6 --> J[client.createSession via devinApiRequest]
    I7 --> J
    J --> K{HTTP ok?}
    K -- 401/403 --> K1[DevinAuthenticationError]
    K -- 429 --> K2[DevinRateLimitedError + parse Retry-After]
    K -- 5xx/other --> K3[DevinApiError]
    K -- abort --> K4[DevinTimeoutError]
    K -- fetch throw --> K5[DevinNetworkError]
    K1 & K2 & K3 & K4 & K5 --> KE[error surfaced / retry-eligible] --> Z
    K -- yes --> L[build local DevinSession status=INITIALIZING, task=QUEUED]
    L --> M[storage.save + credentials.markUsed]
    M --> N{polling running?}
    N -- no --> N1[DevinPollingService.start]
    N -- yes --> O([Session tracked])
    N1 --> O
```

## 2. Polling cycle 🟢

```mermaid
flowchart TD
    A([setInterval every intervalMs ~5s]) --> B[pollOnce]
    B --> C[active = storage.getActive]
    C --> D[recentlyCompleted = terminal & updated<5min & has PRs, only if grace>0]
    D --> E{sessionsToPoll empty?}
    E -- yes --> F{graceCyclesRemaining>0?}
    F -- yes --> F1[decrement grace + notify cycle listeners] --> Z([cycle end])
    F -- no --> F2[stop poller] --> Z
    E -- no --> G[resolveApiClient]
    G --> H{client resolved?}
    H -- no --> H0[log no credentials] --> Z
    H -- yes --> I[if active>0: graceCyclesRemaining=6]
    I --> J[for each session: pollSession]
    J --> K[client.getSession]
    K --> L[resolveSessionStatus status + statusDetail]
    L --> M[re-read fresh session by localId]
    M --> N{response has PRs?}
    N -- yes --> N1[reconcile PRs by URL + detectPrStateChanges]
    N -- no --> O
    N1 --> O{fresh session already terminal?}
    O -- yes --> O1[update PR data only, skip status/tasks] --> P
    O -- no --> Q[update status + syncTaskStatuses + devinUrl]
    Q --> R{status changed?}
    R -- yes --> R1[emit StatusChangeEvent]
    R -- no --> S
    R1 --> S{newStatus==BLOCKED & was not?}
    S -- yes --> S1[emit BlockedSessionEvent -> user action]
    S -- no --> P
    S1 --> P[notify cycle listeners]
    P --> Z
```

## 3. Session status state machine 🟢

```mermaid
stateDiagram-v2

    queued --> initializing
    initializing --> running: running / working
    running --> blocked: blocked / waiting_for_user
    blocked --> running: working
    running --> completed: exit / finished
    running --> failed: error
    blocked --> completed
    running --> cancelled: cancelSession (local-only)
    initializing --> cancelled
    blocked --> cancelled
    completed --> [*]
    failed --> [*]
    cancelled --> [*]
    note right of completed
      Terminal set (status-mapper.ts:77):
      completed / failed / cancelled.
```

## 5. Retry with exponential backoff 🟢

```mermaid
flowchart TD
    A([withRetry op]) --> B[attempt = 1]
    B --> C[run operation]
    C --> D{success?}
    D -- yes --> D0([return result])
    D -- no --> E{isRetryable? 5xx / network / timeout / rate-limited}
    E -- no --> E0[throw original error]
    E -- yes --> F{attempt >= maxAttempts (3)?}
    F -- yes --> F0[throw DevinMaxRetriesExceededError]
    F -- no --> G{RateLimited with Retry-After?}
    G -- yes --> G1[delay = min Retry-After, 30s]
    G -- no --> G2[delay = min base*2^(n-1), 30s + 10% jitter]
    G1 & G2 --> H[onRetry callback + sleep]
    H --> I[attempt++] --> C
```
