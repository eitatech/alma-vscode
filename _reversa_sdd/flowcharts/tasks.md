## 1. Task resolution + provider dispatch 🟢

```mermaid
flowchart TD
    A([getTasksForSpec specId]) --> B[SpecSystemAdapter.getSpecFiles specId]
    B --> C{tasks file path?}
    C -- no --> C0[return empty list] --> Z([End])
    C -- yes --> D[getTasksFromFile specId, filePath]
    D --> E[find provider where canHandle filePath]
    E --> F{provider found?}
    F -- no --> F0[return single isUnsupported placeholder task] --> Z
    F -- yes --> G[provider.getTasks specId, filePath]
    G --> H[parseTasksFromFile utils/task-parser]
    H --> I{parse ok?}
    I -- throws --> I0[return single Failed to parse placeholder] --> Z
    I -- empty --> I1[return empty list] --> Z
    I -- groups --> J[normalizeGroups: flatten -> NormalizedTask, scope ids, map status/execution]
    J --> K([NormalizedTask array])
```
