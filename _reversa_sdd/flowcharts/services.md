# Flowcharts — `services` module

> Source: `src/services/` (incl. `acp/`, `welcome/`). Confidence: 🟢 CONFIRMED unless noted.
> Generated by the Reversa Archaeologist (escavação phase).

## 1. ACP client lifecycle 🟢

```mermaid
stateDiagram-v2
    [*] --> idle
    idle --> starting: ensureStarted() (no connection)
    starting --> starting: concurrent caller awaits shared startingPromise
    starting --> connected: spawn CLI -> ndJsonStream -> ClientSideConnection.initialize(PROTOCOL_VERSION)
    starting --> idle: initialize fails/timeout -> kill child, clear connection
    connected --> connected: sendPrompt / cancel / probeModels / setSessionModel
    connected --> idle: child process exit/error -> reject pending waiters, clear sessions
    connected --> [*]: dispose() (kill child, reject waiters)
```

## 2. sendPrompt + session-update dispatch 🟢

```mermaid
flowchart TD
    A([sendPrompt sessionKey, prompt]) --> B[ensureStarted]
    B --> C{session exists?}
    C -- no --> D[createSession: newSession cwd, mcpServers=[]]
    D --> E[capture model state -> emit session-models-changed]
    C -- yes --> F[reuse sessionId]
    E --> G[connection.prompt: text]
    F --> G
    G --> H[await turn -> stopReason]
    H --> I{key starts with 'once:'?}
    I -- yes --> J[delete single-shot session]
    I -- no --> K([done])

    subgraph updates [Client.sessionUpdate -> dispatchSessionUpdate]
      U([update]) --> U1{sessionUpdate kind}
      U1 -- agent/thought/user chunk --> U2[emit chunk event]
      U1 -- plan / available_commands --> U3[emit plan/commands]
      U1 -- mode/session_info/usage --> U4[emit meta]
      U1 -- tool_call / tool_call_update --> U5[extract affected files + diff stats + guess lang -> emit tool-call]
    end
```

## 3. requestPermission resolution 🟢

```mermaid

    B -- allow --> B1[pick allow option] --> Z([return optionId])
    B -- deny --> B2[return null / reject] --> Z
    B -- ask --> C{remembered decision for ToolKind?}
    C -- allow_always --> C1[re-resolve allow optionId] --> Z
    C -- reject_always --> C2[return null] --> Z
    C -- none --> D{prompter set?}
    D -- no --> D1[default deny/cancel] --> Z
    D -- yes --> E[prompt user]
    E --> F{chose 'always' option?}
    F -- yes --> G[rememberAlwaysDecision by ToolKind]

    G --> Z
    H --> Z
```

## 5. Chat routing + dispatch 🟢

```mermaid
flowchart TD
    A([ChatDispatcher.dispatch prompt]) --> B[ChatRouter.resolve - 60s cache]
    B --> C{decide}
    C -- config 'copilot-chat' --> CC[target=copilot-chat]
    C -- config provider != auto --> D{registered?}
    D -- no --> CC
    D -- yes --> P
    C -- auto + remote workspace --> CC
    C -- auto --> E[host detect -> registry.forHost]
    E -->|none| CC
    E --> P[resolveFor: descriptor.probe]
    P --> P1{installed?}
    P1 -- no --> PA[schedule onboarding install] --> CC
    P1 -- yes --> P2{acpSupported?}
    P2 -- no --> CC
    P2 -- yes --> P3{authenticated?}
    P3 -- no --> PB[schedule onboarding auth] --> CC
    P3 -- yes --> AC[target=acp providerId]

    AC --> X{dispatch}
    X --> X1[rewritePromptForAcp -> sessionManager.send]
    X1 -->|ok| Z([done])
    X1 -->|throws| FB[invalidate cache -> fall back]
    CC --> Y[workbench.action.chat.open query, files?]
    FB --> Y
    Y --> Z
```
