## 1. Read-model snapshot aggregation 🟢

```mermaid
flowchart TD
    A([snapshot]) --> B[collectAgentChatSessions]
    A --> C[collectCloudSessions]
    B --> B1[store.listActive + listRecent]
    B1 --> B2{read ok?}
    B2 -- no --> B3[push degradedReason: local state unreadable] --> B4[return empty]
    B2 -- yes --> B5[merge by id: registry active/recent overrides store]
    B5 --> B6[toAgentChatProjection per session]
    C --> C1{cloudSessionStorage present?}
    C1 -- no --> C2[push degradedReason: cloud storage unavailable] --> C3[return empty]
    C1 -- yes --> C4[cloudSessionStorage.getAll]
    C4 --> C5{read ok?}
    C5 -- no --> C6[push degradedReason: cloud status unreadable]
    C5 -- yes --> C7[toCloudProjection per session]
    B6 & C7 --> D[concat sessions]
    D --> E[sort: bucket rank, then lastVisibleActivityAt desc]
    E --> F[readActiveProvider + cloudProviderCount]
    F --> G([OrchestrationSnapshot + degradedReasons])
```

## 3. Autonomous task execution loop 🟢

```mermaid
stateDiagram-v2
    [*] --> ready
    ready --> queued: claimTask (not running/completed; parallel-safe if others running)
    queued --> running: startTask -> spawn agent-chat session + map session<->task
    running --> completed: completeTask(true) OR session terminal (success)
    running --> failed: completeTask(false) OR session terminal (failure)
    completed --> [*]: fire orchestration.task-completed hook
    failed --> [*]: fire orchestration.task-failed hook
    note right of running
      handleRegistryChange syncs terminal agent
      sessions back to task state (heuristic;
      checks lifecycleState !== "error").
    end note
```

## 4. claimTask eligibility 🟢

```mermaid
flowchart TD
    A([claimTask task]) --> B{execution.state running or completed?}
    B -- yes --> R0[return false]
    B -- no --> C{another task running?}
    C -- yes --> D{task.execution.parallelizable?}
    D -- no --> R0
    D -- yes --> E
    C -- no --> E[clone task, set state=queued, add to activeTasks]
    E --> F[onDidChange.fire] --> R1([return true])
```
