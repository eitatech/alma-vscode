## Fluxo Principal (§1)

1. Workspace open? no → error. 🟢
2. Detect active SDD system (`openspec/` or `.specify`/`specs/`). 🟢
3. If none → QuickPick SpecKit/OpenSpec → save `specSystem` setting + re-init adapter. 🟢
4. **SpecKit** → `constitution.md` exists? confirm overwrite → input directives → `sendPromptToChat('/speckit.constitution <directives>')`. 🟢
5. **OpenSpec** → `openspec/AGENTS.md` exists? confirm overwrite → write default `AGENTS.md` + open. 🟢

## Fluxos Alternativos

- **No QuickPick choice:** abort. 🟢
- **Overwrite declined:** abort. 🟢

## Dependências

- `utils/spec-kit-adapter` (system detect), `utils/chat-prompt-runner` (sendPromptToChat), `workspace.fs`. 🟢
